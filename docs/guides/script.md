# Script: how to

The Script tab reads production's draft scripts: a spreadsheet of every scene, the files that bring ShotGrid's Scenes up to date, and a picture of each scene for its thumbnail.

Open the Script tab. At the top it asks What are you doing? — choose the job below and it walks you through the same steps, ticking each one off as it's done.

**Jobs on this tab**

- [New script drafts issued](#script-new) — When production sends new or revised scripts as PDFs.
- [Scripts in a new layout](#script-layout) — Once per show, or when a show's scripts start to look different.

<a id="script-new"></a>

## New script drafts issued

*When: When production sends new or revised scripts as PDFs.*

Read the scripts, answer anything the app couldn't settle, and send the scenes to ShotGrid with a picture of each.

### 1. Get the latest from ShotGrid

So the app knows which scenes ShotGrid already has, and only adds what's new or changed.

**Press:** `Get the latest`

✓ When it has worked: The status line says when it last updated.

### 2. Read the new scripts

Choose the script PDFs (one draft per episode). The app reads every scene, checks none was missed against the scene numbers in the margin, and makes a picture of each scene. The scripts are only read.

1. Press Choose the scripts and read them, and pick the PDFs — or, under All tools, a whole folder of them.
2. Wait while they're read. With pictures this takes a few minutes.
3. If anything stops the send, the questions open on their own.

**Press:** `Choose the scripts and read them`

✓ When it has worked: A message says how many scenes were read, how many are new or changed, and how many questions are waiting.

### 3. Answer the questions

Anything the app couldn't settle — a scene it couldn't read, a number used twice, a time of day ShotGrid doesn't use. Each has answers you can give: accept it, correct it, add the scene, leave it out. The scene or page is shown beside it. Answers are remembered, and asked again only if the script changes.

1. Press Answer the questions. Rows that stop the send are red.
2. For each, look at the scene or page on the right and choose an answer. Some need something typed or chosen beside them — a heading, a scene number, a Location.
3. Give the usual answer to every row shown clears the simple ones in one go.
4. Press Save answers and read again, and wait while the scripts are read again.

**Press:** `Answer the questions`

✓ When it has worked: The questions line says nothing stops the send.

### 4. Send to ShotGrid

Creates the new scenes, updates the changed ones and puts each scene's picture on it as the thumbnail. You see exactly what will change first; nothing goes until you say so. An existing scene's Location is never changed.

1. Press Preview and send and read the list of new and changed scenes.
2. Press Send.

**Press:** `Preview and send`

✓ When it has worked: A message says how many scenes were created and updated, and how many pictures went.

## Scripts in a new layout

*When: Once per show, or when a show's scripts start to look different.*

Show the app one sample script so it learns where that show puts its scene numbers, headers and revision marks.

### 1. Teach the app the layout

Choose one of the show's scripts. The app measures it, reads it in front of you and shows what it found — and anything it missed — before you save.

1. Press Teach a new layout… and choose one of the show's scripts.
2. Check the name and the file names it should be used for (for example show\_\*.pdf).
3. Press Measure and try it. Check the scenes it found look right and nothing was missed.
4. If something's wrong, correct a value against the page and try again.
5. Press Save the layout.

**Press:** `Teach a new layout…`

✓ When it has worked: The Script layouts card lists the new layout.


## Words you'll see

- **Draft** — One issue of an episode's script. Revised pages carry a colour and a date.
- **Scene heading** — The line that opens a scene: its number, INT or EXT, the set and the time of day.
- **Eighths** — A scene's length: a page is eight eighths.
- **Layout** — Where a show's scripts put their scene numbers, headers and revision marks. Taught once per show.
- **Import (ShotGrid)** — Uploading a CSV file into a ShotGrid page to create or update records.
- **Thumbnail** — The small picture ShotGrid shows for a record — here, the scene as it looks in the script.
