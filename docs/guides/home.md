# Home: how to

The Home tab shows where the project stands at a glance — shots, progress, budget spend and hot costs — and brings in the latest from ShotGrid. It also makes the packs the crew open on their phones.

Each job below lists what to press, in order, and what you'll see when it has worked.

**Jobs on this tab**

- [Start of the day](#home-day) — Each morning, and before any job that needs today's figures.
- [Make the phone pack](#home-phone-pack) — After a sync, whenever the schedule or the scripts change.
- [Make the wrangle pack](#home-wrangle-pack) — During the shoot, after a sync, when the wranglers need the latest slates.

## Start of the day

*When: Each morning, and before any job that needs today's figures.*

Bring the project up to date from ShotGrid and see where it stands.

### 1. Get the latest from ShotGrid

Downloads the newest shots, versions, costs and schedule to this computer. Every tab and report works from the last time this was done.

**Press:** `Sync Now`

✓ When it has worked: The line under the project name says when it last updated, and how many shots and versions came in.

### 2. Look over the cards

Shots, Finalled, In Progress and Waiting count the shots by their ShotGrid status. Budget Spend is what has been spent against the budget set in Settings: green, amber past 85%, red once over.

1. A Hot Costs banner means shots are flagged for cost: it says how many, and what they add up to.
2. An After Action reports banner means day reports are waiting on the Onset tab.

### 3. Open the Weekly Overview

Makes the week at a glance for producers (progress, spend and hot costs) and opens it in your web browser.

**Press:** `Weekly Overview`

✓ When it has worked: The report opens, and a message says it's ready.

### 4. Find the saved reports

Opens the folder every report is saved in: the Export Dir set in Settings, or a folder on your Desktop.

**Press:** `Reports Folder`

## Make the phone pack

*When: After a sync, whenever the schedule or the scripts change.*

One file of the coming shoot days, scenes and script pages, to open on your phone.

### 1. Get the latest from ShotGrid

The pack is a snapshot of the last sync, so bring it up to date first.

**Press:** `Sync Now`

✓ When it has worked: The line under the project name says when it last updated.

### 2. Point it at the script pages (once, if needed)

Only on a computer that didn't read the scripts itself: press the page button beside Make the phone pack and choose the folder the Script tab saved into (a copy on a shared drive will do). It is remembered for this project.

✓ When it has worked: A message says where the sides will come from.

### 3. Make the pack

One file of every shoot day, scene, set and VFX breakdown line, with the script pages (sides) for the scenes shot in the next three weeks. No costs or crew contact details go in it.

1. The first time, it asks where to save the pack. Choose a Google Drive folder so your phone can open it; the folder button beside it changes this later.
2. If it says no sides were found, do the step before this one, then make the pack again.

**Press:** `Make the phone pack`

✓ When it has worked: A message says how many shoot days are coming up and how many scenes have their sides.

### 4. Open it on your phone

Open the pack from Drive in the phone app. It works offline, and nothing goes back to ShotGrid.

## Make the wrangle pack

*When: During the shoot, after a sync, when the wranglers need the latest slates.*

One file of every slate for the wranglers to look up on their phones.

### 1. Get the latest from ShotGrid

So every slate, take and picture is today's.

**Press:** `Sync Now`

✓ When it has worked: The line under the project name says when it last updated.

### 2. Make the pack

One file of every slate (its takes, cameras, lenses, notes and picture) with the last two weeks' reference contact sheets, saved in the phone pack's folder. Make it on the computer that gathers the onset paperwork, so each take carries the wranglers' lens details.

**Press:** `Make the wrangle pack`

✓ When it has worked: A message says how many slates went in, how many have a picture, and how many contact sheets.

### 3. Open it on the phone

Open the pack in the wrangle app on the phone. No costs go in it.


## Words you'll see

- **Sync** — Bringing the latest from ShotGrid down to this computer. Every tab and report works from the last sync.
- **Finalled / In Progress / Waiting** — Shots grouped by their ShotGrid status, using the groups set for the project.
- **Hot cost** — A shot flagged in ShotGrid because its cost needs watching.
- **Phone pack** — One file of the coming shoot days, scenes, VFX work and script pages, to open on a phone.
- **Sides** — The script pages for a scene, as the Script tab pictured them.
- **Wrangle pack** — One file of every slate (takes, camera and lens details, notes and picture) for the wranglers' phones.
