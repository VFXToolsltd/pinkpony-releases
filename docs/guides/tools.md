# Tools: how to

The Tools tab opens the separate VFX tools that work alongside this app, each in its own window. It only starts them: each tool is installed on the computer on its own.

Each job below lists what to press, in order, and what you'll see when it has worked.

## Set up a tool on this computer

*When: The first time on a new computer, or when a tool's card says Not found.*

Install the tool once, then show the app where it is. It's remembered on this computer.

### 1. Install the tool

Each tool is its own program and comes with an install script. Run it once on this computer; ask whoever looks after the tools if you don't have it.

### 2. Show the app where the tool is

If the card says Not found, its Launch button can't be pressed. Press the card's magnifying-glass button and choose the tool's program file.

1. On the Tools tab, find the tool's card.
2. Press the magnifying-glass button.
3. Open the folder the tool was installed in and choose its program file (it ends in .py).
4. To check, the folder button opens the folder the card now points at. Wrong one? Press the magnifying-glass button again and choose the right file.

**Press:** `Show Pink Pony where this tool is`

✓ When it has worked: The card says Ready and its Launch button can be pressed.

## Collate the camera reports

*When: When the set's camera reports need gathering into one workbook.*

Open the Onset Collator. It gathers the set's camera reports into one Excel workbook and a tidy day-by-day library of PDFs.

### 1. Open the Onset Collator

Starts the tool in its own window, where the collating is done. Closing this app leaves the tool open.

1. On the Tools tab, find the Onset Collator card.
2. If it says Not found, set it up first (Set up a tool on this computer).
3. Press Launch, then work in the tool's own window.

**Press:** `Launch`

✓ When it has worked: A message says it's opening, and the tool's window appears a moment later.

## Words you'll see

- **Tool** — A separate program that works alongside this app, with its own window and its own version.
- **Launch** — Starts the tool in its own window. Closing this app leaves it running.
- **Ready / Not found** — Whether this computer knows where the tool is. Not found means show it once.
- **Program file** — The file that starts a tool. It ends in .py and sits in the tool's own folder.
