# Upload: how to

The Upload tab sends a delivery folder to ShotGrid: movies go on their shots (or slates), PO, invoice and bid documents onto their records, and frame sequences are noted but never uploaded. You see where every file goes before anything is sent.

Each job below lists what to press, in order, and what you'll see when it has worked.

**Jobs on this tab**

- [Send a delivery to ShotGrid](#upload-delivery) — When a vendor's delivery arrives, or while shooting, to put movies on their slates.

## Send a delivery to ShotGrid

*When: When a vendor's delivery arrives, or while shooting, to put movies on their slates.*

See where every file goes, fix anything that's wrong, then send.

### 1. Get the latest from ShotGrid

Press Sync Now on the Home tab first. The check matches files against the last sync, so a shot added since then won't be found.

### 2. Choose the folder

Pick the delivery folder. Folders inside it are included.

**Press:** `Choose…`

### 3. Choose what movies go on

Leave Link movies to on Shots for a delivery. Choose Slates while shooting, and each movie becomes its slate's picture in ShotGrid.

1. Every new folder starts on Shots again.

### 4. Check the folder

Works out where every file would go. Nothing is sent, and nothing leaves this computer.

**Press:** `Check Folder`

✓ When it has worked: A message says how many files are ready to send, and the table lists every file.

### 5. Read the table

Each file shows where it goes and its status: Ready, Review (it will go, but read why first), Blocked (it can't go) or Skipped. Click a row to see why, under the table.

1. Wrong place? Click its Goes to cell and type the right code. It's checked again straight away.
2. Untick any file you don't want sent. Blocked files can't be ticked.
3. A PO, invoice or bid document goes onto the record ShotGrid already has with the number in its file name. To create a new one, use Add paperwork on the Finance tab.
4. Frame sequences are noted on their shot, never uploaded.

### 6. Send the ticked files

Shows how many files of each kind will go, and asks you to confirm. Sending can't be undone from the app.

1. Press Send Ticked Files.
2. Read the summary, then press Yes.

**Press:** `Send Ticked Files`

✓ When it has worked: A message says how many files were sent, and the log beside the table lists each one.

### 7. Check the record

The folder now holds a delivery summary PDF and an upload log. Movies sent to shots are also gathered into a ShotGrid review playlist named after the folder.

1. Where the project is set up for it, each shot's status also changes to show it has been delivered.

**Press:** `Open Folder`

## When files go to the wrong place

*When: When the check keeps reading a kind of file name wrongly.*

See how file names are matched to shots and records.

### 1. Look at the rules

Lists, in order, what each kind of file is recognised by. The first rule that fits a file name wins.

1. For a single file, correcting its Goes to cell in the table is quicker.
2. Changing a rule is technical, so ask whoever set up the app. Check tests a change, and Save keeps it.
3. Restore Defaults puts the project back on the standard rules.

**Press:** `Routing Rules…`


## Words you'll see

- **Delivery** — A folder of files a vendor sends: movies, frames and documents.
- **Version** — One submitted movie of a shot's work in ShotGrid.
- **Frame sequence** — A shot's frames as numbered image files. They're noted in ShotGrid but never uploaded.
- **Ready / Review / Blocked / Skipped** — Ready will be sent. Review will be sent, but has something to read first. Blocked can't be sent. Skipped is a file the app ignores on purpose.
- **Review playlist** — The ShotGrid playlist the app makes of the movies just sent, named after the folder.
